# Hub 保管委託者的第三方服務憑證

這個站台原本只碰一種憑證：代跑者的 Claude 額度。現在決定**再收一種** ——
委託者為了讓某個指令連得到公司內部服務（第一個是 Observ API）而交出的
**服務憑證**，hub 加密保管，job 啟動時只注入該委託者自己的那一份。

起因是一位 PM 拿到了 observ-api skill 卻跑不起來：他不會設 `.env`、
用的是跑在 Anthropic 雲端沙箱的 Claude app、而他是 Windows，教他裝 WSL
就哀哀叫。這三件事裡 boba 本來就解掉了後兩件；憑證是剩下那件。

## 這個決定的不對稱

**外洩的受害者不是交出憑證的那個人。** 代跑 token 外洩，倒楣的是代跑者
（他自己的額度、他自己名下的帳號）—— README 與 ADR-0001 都是照這個前提寫的。
服務憑證外洩，倒楣的是**公司的資料**，而委託者只是那個剛好有權限的人。

這是這個專案至今最大的一次邊界改動，比 2026-09-22 那次「憑證會離開你的機器」更遠 ——
那次改的是誰承擔風險的**程度**，這次改的是**誰承擔**。

## Considered Options

**不碰，每次讓使用者把憑證貼進提交頁。** 最乾淨，但等於沒解原本的問題：
「每次要用都得先去別的地方把東西配好」正是他失敗的那一步。

**共用服務帳號，hub 保管一份大家用。** 最省事，而且對使用者最無感。
否決的理由是 Observ 那端的 audit log 會看到清一色同一個帳號，出事查不出是誰 ——
而這個專案已經為了「每個人交自己的 token、不是一個帳號大家共用」辯護過一次
（README「還成立的」那段），這裡沒有理由反過來。

## Consequences

- **缺憑證在使用的當下才問，不做前置設定頁。** 選了需要憑證的指令、而他還沒交過，
  就在提交頁原地要，存下來下次不用。要求使用者先逛設定頁才知道自己缺什麼，
  是他已經失敗過一次的模式。
- **hub 在收單時就驗一次憑證**（走指令宣告裡的 `verify`）。理由是這個專案的社交契約
  建立在「不浪費代跑者的額度」上 —— 貼錯、過期、權限不足都要在**花掉別人的額度之前**
  被擋下來，不是跑起來才失敗。代價是 hub 自己要連得到那些服務，那跟 job 容器的
  egress 是兩條獨立的路。
- **服務憑證與代跑 token 在資料模型上不共用任何東西。** 兩者的交出者、受益者、
  受害者、有效期與撤銷方式全都不同，合併只會讓下一個人搞混。
- **證據很薄，而我們知道。** 決定的時候只有一個指令（observ-api）、一個使用者、
  一次轉述。之所以仍然照「平台」的形狀做，是因為指令清單那個 bug（見 SPEC §4.13）
  已經證明「兩份手寫的事實會互相漂移」—— 而不是因為我們相信第五個指令一定會來。

## 2026-09-24 修訂：第一個指令做出來時，帳密保管那條沒有做

實作「查 Observ 事件」（第一個真的需要服務憑證的指令）時發現兩件寫這篇時不知道的事：

1. **登入 boba 用的就是 Observ 帳密**，瀏覽器手上本來就有一張 Observ access token。
2. 那張 token 是 Keycloak JWT，**效期 72 小時**（2026-09-24 對 production 實測），而一個 job
   從送出到跑完最多 25 分鐘（排隊 15 ＋ 執行 10）。

所以「另收一份帳密、加密保管、派單時換票」變成多餘的：hub 不需要保管任何能換票的東西。
改成 —— **瀏覽器在送出那個指令時把登入 token 一起帶上**；hub 收單時驗它是本人的
（`whoami`）、剩餘效期夠一小時；加密存在 job 上**只到派單那一刻**，交給 worker 就清掉；
以環境變數注入 job 容器，容器裡只有一支腳本碰得到它。

這保住了上面三條 Consequences 的前兩條的**用意**（在花掉代跑者額度之前驗、每個人用自己的
身分），砍掉了最危險的那一段（hub 長期保管一份公司帳密）。指令宣告裡的 `verify` 因此沒有用到。

**不變的**：共用帳號仍然否決（同上面的理由；middleware 還多一層 —— 它靠身分區分內部與
vendor 使用者，決定看得到什麼）。**新增的一條**：這張 token 是委託者對 Observ 的完整身分，
不是只能查事件的東西；所以它只能在 prompt 以那個指令開頭時被送、被存，其他 job 上不准有它。

**如果第二個指令的外部服務不是 Observ 登入的**（沒有現成 token 可用），上面那條帳密保管路
才會需要真的做。到那時再做，並回頭改這一段。
